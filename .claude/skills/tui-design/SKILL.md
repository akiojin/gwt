## When to use

Design terminal interfaces for the requested workflow and the project’s rendering stack. Choose a coherent visual direction that supports efficient terminal use.

## Completion

Deliver readable hierarchy, deliberate layout, and consistent theme behavior within terminal capabilities. Treat examples as design options and preserve accessibility and project conventions.
