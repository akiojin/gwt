Search machine-local work notes for relevant failures and reusable decisions. Use the original note to assess whether its context matches the current work.

## Completion

Return relevant findings with context and a concrete implication. A memory hit is evidence to evaluate, not authority to expand scope; report missing tooling explicitly.
