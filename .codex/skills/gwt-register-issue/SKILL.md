## When to use

Normalize a new request, search for an existing owner, and choose plain or design-required registration. Existing Issues proceed through [gwt-execute](../gwt-execute/SKILL.md).

## Completion

Return one owner and its next action. Preserve duplicate checks, Spec Status routing, canonical issue mutations, autonomous eligibility rules, and create → edit → roundtrip verification for design-required artifacts.
