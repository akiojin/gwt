## When to use

Compatibility entrypoint for approved implementation work. Continue through [gwt-execute](../gwt-execute/SKILL.md) with the same owner; this alias does not create another execution lifetime.

## Completion

Complete the scoped implementation through TDD, fresh canonical verification, and the repository’s Ready PR/CI auto-merge path. Keep unresolved work visible and never represent push-only evidence as delivery.
