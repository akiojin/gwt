## When to use

Find existing work before choosing or creating an Issue owner. Search terms should describe the behavior and intended scope.

## Completion

Return relevant Issue links and explain their relationship to the request. Distinguish a verified empty result from unavailable or incomplete tooling; inspect candidate owners before reusing them.
