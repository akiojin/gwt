## When to use

Find likely implementation or documentation paths by behavior or concept. Follow promising hits with direct source inspection.

## Completion

Return useful paths and their relevance. Choose the correct collection, distinguish semantic candidates from proof, and report tooling failures rather than treating them as no results.
