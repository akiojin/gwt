gwt 全画面刷新モック — 対話型

刷新案を、現行アプリと同じ骨格で触れる形に組み直したモックです。各画面は独立したページで、それぞれ固有の URL を持ちます。起点は開始画面（現行の Hub、URL: /）で、プロジェクトの一覧・最近・開く・GitHub から取り込む導線が集まります。プロジェクトを開くと、そのプロジェクト専用のページ（URL: /p/<hash>）へ移ります——標準では新しいブラウザタブで開き、複数プロジェクトを並べて見るのはブラウザタブの役割です（アプリの中に横断の入れ物は作りません）。開始画面には PM の要約ブロック を置きます（独立した PM のページは作りません）。PM の状態と、いちばん急ぐ判断と残りの件数だけを見せ、判断は各プロジェクトのページで完結させます。アプリ全体の設定は、開始画面から開く設定ページに置きます。1画面＝1文脈、主役は1つ、を原則に要素を絞っています（2026-11-12、実際に触った本人のフィードバック、「タブ＝ブラウザのタブ」の訂正、PM 要約ブロックの決定を受けて改修。モックの文言は内容を評価できるよう日本語にしています）。
